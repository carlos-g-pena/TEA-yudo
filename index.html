🧩 Guía de Accesibilidad & Plataforma TEA-yudo

TEA-yudo integra los 4 pilares esenciales de inclusión en el aula escolar:

1. Comunicador SAAC: Tablero aumentativo con clave de color Fitzgerald y pictogramas ARASAAC. Utiliza la Web Speech API para dar voz a las frases del niño.
2. Agenda Visual (Rutina): Anticipación estructurada de tareas escolares. Permite marcar logros con tachado visual y reforzamiento auditivo de éxito.
3. Zona Calma / SOS: Termómetro interactivo de 3 estados y respiración guiada para prevenir o mitigar crisis sensoriales de forma oportuna.
4. Bitácora PIE & Seguridad: Historial de interacciones de cada estudiante, protegido con el PIN personal del profesional para que el estudiante no modifique registros confidenciales.
5. Estudiantes y Accesos: Cada profesional ingresa con su cuenta y gestiona a sus estudiantes. Al iniciar la sesión de un estudiante se registra su acceso (inicio, término, duración y actividad), visible en la pestaña Estudiantes.
